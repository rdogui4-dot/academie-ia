# Présentations de formation

Les quatre niveaux disposent d’un lecteur HTML local, de 144 diapositives et de téléchargements PDF et PowerPoint. Les polices Poppins et DejaVu Sans sont hébergées avec le site. Le logo complet officiel reste inchangé.

Le bouton « Ouvrir le diaporama » commence à une diapositive pertinente pour l’étape sélectionnée. Le lecteur permet ensuite de parcourir toutes les slides du niveau : il sert de support de révision, pas de contrôle d’accès. Les étapes, le carnet et les règles de progression du cours restent gérés par learning.js. La consultation des slides ne valide pas une étape et ne délivre aucun certificat.

Les manuels originaux gardent leurs liens et leur pagination. Les slides les accompagnent sans remplacer les ateliers de code, les questionnaires et les grilles détaillées. Les anciens liens vers les PDF importés dans Canva sont masqués dans la configuration fournie. L’activation éventuelle du tuteur IA reste distincte.

La lecture HTML fonctionne sans Canva et sans bibliothèque JavaScript distante. La navigation au clavier utilise les flèches hors champs de saisie. Les titres reçoivent le focus après un changement de slide et le compteur annonce la position. La mise en page s’empile sur les petits écrans.

Vérifications réalisées : syntaxe JavaScript, liens vers les fichiers, navigation et bornes des quatre diaporamas, raccordement des 41 étapes et création des lecteurs intégrés dans un DOM de test. Le navigateur de test n’a pas pu être installé dans cet environnement : contrôle visuel dans le navigateur de l’utilisateur à effectuer avant publication. Les PowerPoint et PDF ont fait l’objet d’une vérification séparée lors de leur création.

Cette livraison ne publie rien. L’installateur Windows vérifie le dépôt, crée une sauvegarde et applique une variante du patch compatible avec son état. Il refuse les changements locaux non enregistrés et les configurations incompatibles. Il n’écrit pas dans apps-script/Code.js et ne lance ni fetch, ni merge, ni push.
