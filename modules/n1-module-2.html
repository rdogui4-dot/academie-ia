Objectifs du module

  • Définir l’IA générative avec ses propres mots.
  • Identifier les principaux contenus qu’elle peut produire.
  • Repérer un usage adapté à son activité.

La leçon

L'intelligence artificielle générative désigne des systèmes capables de produire du contenu à partir d'une instruction fournie par un utilisateur.

Ce contenu peut prendre différentes formes : texte, image, audio, vidéo ou code.

Les modèles génératifs apprennent à partir de grandes quantités de données afin de produire de nouvelles réponses à partir des demandes qui leur sont adressées.

  • Texte
  • Images
  • Audio
  • Vidéo
  • Code

À retenir

Une IA générative produit du contenu à partir d’une demande. Ses réponses doivent toujours être examinées avant utilisation.
